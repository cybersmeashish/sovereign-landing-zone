# Landing-zone acceptance

1. Obtain accountable acceptance of the workload boundary register.
2. Test the intended service path and a denied cross-boundary path.
3. Check operator privilege, revocation and emergency access.
4. Establish which authentication, keys, DNS, time and packages remain available during disconnection.
5. Exercise update and evidence-disclosure decisions in an authorized representative environment.
6. Restore configuration, data and keys within the approved recovery boundary.
7. Record the exact provider/platform version, deployment assumptions, observed output and limitations.

Passing a document review is distinct from passing these environment-specific gates.
